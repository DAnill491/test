 Конвертер валют 
 1. Задача
Написать консольную утилиту на Python, которая переводит рубли (RUB) в доллары (USD) и евро (EUR) по фиксированному курсу.
 2. Требования к реализации
Язык: Python 
Файл программы должен называться `converter.py`.
 Курсы валют в код: `1 USD = 90 RUB`, `1 EUR = 100 RUB`.
 Программа должна запрашивать у пользователя сумму в рублях и валюту (`USD` или `EUR`).
 Если введена неверная валюта или отрицательная сумма — выводить понятное сообщение об ошибке
 3. Критерии приемки (Тест-кейсы)
Тест 1:** Ввод `9000` и `USD` -> Вывод: `100.00 USD`
Тест 2:** Ввод `5000` и `EUR` -> Вывод: `50.00 EUR`
Тест 3:** Ввод `-100` -> Вывод: `Ошибка: сумма должна быть больше нуля.`
Тест 4:** Ввод `1000` и `GBP` -> Вывод: `Ошибка: неподдерживаемая валюта.`
